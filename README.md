# KadrRoom

KadrRoom — приложение для совместного просмотра фильмов и прослушивания музыки. В комнате до пяти человек. Ведущий выбирает медиа из серверного каталога и управляет общим плеером. Участники могут говорить и включать камеры. Владелец каталога загружает и публикует файлы через админку.

## Что уже есть

В стартовой версии есть Go API с двумя демонстрационными записями и веб-каталог на Angular и TypeScript. Карточки описывают вымышленные ролики и показывают статус «Видео недоступно». Интерфейс показывает загрузку, пустой каталог и ошибку с возможностью повторить запрос.

## Локальный запуск

Нужны Go 1.26 и Node.js 22 от 22.22.3, 24 от 24.15.0 или 26. Для проверки Go также нужен `golangci-lint` v2, собранный с поддержкой Go 1.26. Все команды выполняются из корня проекта.

Установи зависимости npm-workspace.

```sh
npm install
```

В одном терминале запусти API.

```sh
go run ./apps/catalog-api
```

Проверь API напрямую.

```sh
curl http://127.0.0.1:8080/healthz
curl http://127.0.0.1:8080/v1/catalog
```

В другом терминале запусти Angular.

```sh
npm run dev
```

Открой `http://127.0.0.1:5173`. Angular CLI отправляет запросы `/v1/` на Go API.

`npm run build` проверяет типы и шаблоны, затем собирает интерфейс в `apps/web/dist/browser`. `npm run preview` запускает Angular с производственной конфигурацией на `http://127.0.0.1:4173`.

## Проверки

| Команда                | Назначение                                                                  |
| ---------------------- | --------------------------------------------------------------------------- |
| `npm run format`       | Форматирует исходники и конфигурацию с отступом в четыре пробела            |
| `npm run format:check` | Проверяет форматирование                                                    |
| `npm run lint`         | Запускает ESLint со строгими правилами TypeScript и Angular и golangci-lint |
| `npm run typecheck`    | Проверяет типы приложения, тестов и пакета контрактов                       |
| `npm test`             | Запускает юнит-тесты и тесты HTTP, проверяет гонки и измеряет покрытие      |
| `npm run check`        | Проверяет формат, линтеры, типы, юнит-тесты и сборку                        |
| `npm run test:e2e`     | Запускает Go и Angular для Playwright в Chromium, Firefox и WebKit          |

Перед первым запуском Playwright установи браузеры командой `npx playwright install`. GitHub Actions выполняет `npm run check` и `npm run test:e2e` на PR.

`npm run test:unit:web` требует 100% покрытия строк, веток и функций модуля `catalog.ts`.

## Общие контракты

`@kadrroom/contracts` в `packages/contracts/` содержит общие TypeScript-типы. При изменении публичного контракта обнови версию пакета и зависимость приложения, затем проверь совместимость. Тег `contracts-v<версия>` создаёт GitHub Release с npm-архивом пакета. Версия в теге должна совпасть с `packages/contracts/package.json`.
