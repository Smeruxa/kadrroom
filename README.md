# KadrRoom

KadrRoom — веб-приложение для совместного просмотра видео и прослушивания музыки. Ведущий выбирает запись из каталога, приглашает до четырёх гостей по ссылке и управляет общим плеером. В комнате можно говорить и включать камеры. Для загрузки и публикации записей есть отдельная админка.

## Стек

Angular и TypeScript, Go, PostgreSQL, LiveKit для звонков и FFmpeg для обработки медиа.

## Локальный запуск

Нужны Docker с Compose и OpenSSL. Выполните команду из корня репозитория.

```sh
bash tools/local/stack.sh testing up -d --build
```

- [Сайт](http://127.0.0.1:4173)
- [Админка](http://127.0.0.1:4183)

Для первого входа в админку зарегистрируйте `operator@example.test` на сайте и подтвердите адрес по письму в [Mailpit](http://127.0.0.1:8025).

## Проверки

Для локальных проверок нужны Go 1.26, golangci-lint v2 и одна из версий Node.js, указанных в `package.json`.

```sh
npm ci
npm run check
npx playwright install
npm run test:e2e -- catalog.spec.ts
```
